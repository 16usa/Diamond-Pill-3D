# Diamond Pill 3D

Minimal full-screen Three.js scene for Replit: pure black background and one floating faceted crystal/diamond pill. No buttons, text, menus, or image background.

## Run

```bash
npm install
npm run dev
```

Vite listens on `0.0.0.0`, so Replit Preview can open it.

## v2 fixes

- responsive camera framing for iPhone/portrait screens
- pill always fits fully inside the viewport
- pure black background (no reflective floor)
- reduced exposure/bloom to preserve diamond facets
- subtler sparkles and controlled lighting
- resize/orientation handling
